Safe Shared Excel Sync & Cloud Deployment

Zero file locking architecture, OneDrive synchronization, and Firebase Cloud Backend.

1. Non-Locking Binary Stream

Reads in-memory binary bytes (io.BytesIO) and releases file handles in under 2ms. Users can keep Excel open in OneDrive without "File Locked" errors.

🔥 2. Firebase Cloud Firestore

Real-time Firestore listeners (onSnapshot) push updates globally to all web users in under 50ms without keeping any local computer awake.

3. Future File Auto-Discovery

Drop any new .xlsx file into any folder (e.g. HVAC/, Inventory/). The engine automatically parses sheets, renders a table view, and adds a navigation tab!
